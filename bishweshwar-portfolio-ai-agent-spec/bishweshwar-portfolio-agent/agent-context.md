# Agent Context Intake

The user will provide personal source material after this specification.

Expected inputs:

```text
Resume:
<uploaded PDF/file>

LinkedIn:
<URL>

GitHub:
<URL>

Medium:
<URL>

Other:
<files/notes>
```

## Intake procedure

1. Read the complete resume.
2. Extract factual profile/experience data.
3. Inspect LinkedIn information supplied by the user.
4. Inspect GitHub repositories supplied by the user.
5. Inspect Medium posts supplied by the user.
6. Build `content/content-inventory.md`.
7. Flag contradictions.
8. Ask for clarification only where necessary.
9. Then implement.

## Important

Do not use personal context or old information as a substitute for the files/links supplied for this project when those sources are available.

The website should reflect what the user wants publicly represented, not everything that may be known about the user.
