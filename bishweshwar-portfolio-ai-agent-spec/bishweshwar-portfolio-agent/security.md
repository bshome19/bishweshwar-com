# Security and Privacy

## Principles

The portfolio is public by design, but personal information must be intentionally exposed.

## Never publish without explicit approval

- Personal phone number
- Home address
- Private email
- Government IDs
- Private documents
- Private repository URLs
- Employer-internal information
- Credentials
- API keys

## Contact form

Validate:

- Name
- Email
- Message

Protect against:

- Spam
- Injection
- Oversized payloads
- Automated abuse

Do not log full message bodies unnecessarily.

## External links

Use safe external-link behavior when opening new tabs.

## Dependencies

Keep dependencies minimal and updated.

Run vulnerability checks periodically.

## Third-party services

Document every third-party service and why it exists.

Do not add analytics, trackers, fonts, widgets, or scripts without a clear reason.
